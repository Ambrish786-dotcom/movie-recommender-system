# Content-Based Movie Recommendation System

An end-to-end Machine Learning web application built using Python, scikit-learn, and Streamlit, deployed on Render.

## Dataset
- **Dataset Name:** TMDB 5000 Movie Dataset
- **Kaggle Link:** https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

## Features
- Text preprocessing (lowercase conversion, punctuation removal, stopword filtering).
- TF-IDF Vectorization with unigrams and bigrams.
- Cosine similarity computation for item-to-item matching.
- Interactive Streamlit web interface.
